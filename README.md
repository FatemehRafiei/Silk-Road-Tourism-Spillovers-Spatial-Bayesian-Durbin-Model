# Silk-Road-Tourism-Spillovers-Spatial-Bayesian-Durbin-Model
Data and code for analyzing tourism spillovers across Silk Road countries using a Bayesian Spatial Durbin Model (BSDM).
This repository contains all data, code, and workflow necessary to reproduce the analysis described in the Research Element:
"Construction of Spatial Proximity Matrices and Bayesian Spatial Durbin Model Workflow for Tourism Spillover Analysis in the Silk Road Region"
(Annals of Tourism Research: Empirical Insights, 2025 — under review)
